ECHO HOLLOW — WEBSITE FILES

Files:
- index.html: website structure
- style.css: layout, colours and animation styling
- script.js: button behaviour and random questions
- echo_hollow_green_frame.png: supplied green frame artwork
- qr_code.png: supplied QR code

Preview locally:
1. Keep all files together in the same folder.
2. Double-click index.html to open it in a modern browser.

Publish with GitHub Pages:
1. Sign in to GitHub and create a new PUBLIC repository, for example echo-hollow.
2. Upload all five website files from this folder into the repository's root (not the folder itself).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the Pages deployment to finish. The URL will look like https://YOUR-USERNAME.github.io/echo-hollow/.

GitHub Pages serves static files, so this website runs in the browser and does not need Python or Tkinter.
